NETWORK INFRASTRUCTURE DESIGN

Role: Network Administrator

Objective: Designed a scalable network infrastructure for a corporate environment consisting of two buildings with over 300 devices (PCs & Servers). The goal was to ensure seamless connectivity between segmented LANs using distinct IP classes (Class A & B).

Solution:

  • Topology Design: Implemented a hierarchical topology using Cisco ISR 4321 Routers and Catalyst 2960 Switches to manage traffic for 300+ users[cite: 15].
  • Routing Configuration: Configured Static Routing across Autonomous Systems to bridge the WAN connection between the two buildings.
  • Wireless Integration: Deployed Access Points with WPA2-PSK security for flexible mobile connectivity[cite: 77].
  • Budgeting: Developed a comprehensive cost estimation (approx. IDR 1.9 Billion) covering hardware specifications and installation fees.

Reflection - WEB PROJECT

WHAT: I developed a web application that bridges the gap between static design mockups and functional development, incorporating a complete user data capture system that processes and stores information in a relational database. This project required both frontend interface design and backend database management.

SO WHAT: This project revealed the complexity of full-stack development and the importance of seamless communication between design and development teams. I realized that decisions made during the design phase have significant implications for database structure and backend logic. Poor planning at the start creates technical debt later. Additionally, I learned the critical importance of data validation and security considerations when handling user information.

NOW WHAT: I will adopt a more collaborative approach by establishing clear specifications before development begins, implement robust data validation mechanisms, and prioritize security practices from the outset. I also plan to deepen my knowledge of database optimization and explore frameworks that can accelerate development while maintaining code quality.

Reflection - UI/UX DESIGN

WHAT: I conducted user research to identify pain points in the freelance graphic design marketplace, then created user flows, low-fidelity wireframes, and high-fidelity interactive prototypes for Vishire. This project was grounded in user-centered design principles, with a focus on translating research findings into tangible interface solutions.

SO WHAT: The process demonstrated that good design isn't about personal preference—it's about solving real user problems backed by research. I discovered that empathy and understanding user pain points are far more valuable than aesthetic choices. Iterative feedback and usability testing revealed assumptions I had made were often wrong, highlighting the dangers of designing without user validation.

NOW WHAT: I will continue to prioritize user research and testing in all future design projects, implementing structured feedback sessions with actual users rather than relying on assumptions. I aim to develop a more systematic approach to UX design by documenting design decisions and their rationale, and I plan to explore advanced prototyping tools that allow for better user testing and interaction simulation.

Reflection - NETWORK INFRASTRUCTURE DESIGN

WHAT: I designed a comprehensive network infrastructure for a corporate environment spanning two buildings with 300+ devices. This involved creating a hierarchical topology using Cisco equipment, configuring static routing protocols, integrating wireless access points, and developing a complete budget estimate (IDR 1.9 Billion) covering hardware and installation.

SO WHAT: This project demonstrated that network administration requires a holistic approach considering not just technical specifications, but also scalability, security, budget constraints, and future organizational growth. I realized that network design decisions have lasting implications—poor planning becomes exponentially more expensive to remediate later. Additionally, I learned that successful infrastructure projects require strong documentation and stakeholder communication to justify technical decisions in business terms.

NOW WHAT: I will deepen my expertise in network security protocols and redundancy planning to design more resilient systems. I plan to pursue advanced certifications in network administration (CCNA) to strengthen my technical credentials. Additionally, I will develop better skills in presenting technical concepts to non-technical stakeholders, as infrastructure projects increasingly require business case justification and cost-benefit analysis.
