NETWORK INFRASTRUCTURE DESIGN

Role: Network Administrator

Objective: Designed a scalable network infrastructure for a corporate environment consisting of two buildings with over 300 devices (PCs & Servers). The goal was to ensure seamless connectivity between segmented LANs using distinct IP classes (Class A & B).

Solution:

  • Topology Design: Implemented a hierarchical topology using Cisco ISR 4321 Routers and Catalyst 2960 Switches to manage traffic for 300+ users[cite: 15].
  • Routing Configuration: Configured Static Routing across Autonomous Systems to bridge the WAN connection between the two buildings.
  • Wireless Integration: Deployed Access Points with WPA2-PSK security for flexible mobile connectivity[cite: 77].
  • Budgeting: Developed a comprehensive cost estimation (approx. IDR 1.9 Billion) covering hardware specifications and installation fees.

Reflection - NETWORK INFRASTRUCTURE DESIGN

WHAT: I designed a comprehensive network infrastructure for a corporate environment spanning two buildings with 300+ devices. This involved creating a hierarchical topology using Cisco equipment, configuring static routing protocols, integrating wireless access points, and developing a complete budget estimate (IDR 1.9 Billion) covering hardware and installation.

SO WHAT: This project demonstrated that network administration requires a holistic approach considering not just technical specifications, but also scalability, security, budget constraints, and future organizational growth. I realized that network design decisions have lasting implications—poor planning becomes exponentially more expensive to remediate later. Additionally, I learned that successful infrastructure projects require strong documentation and stakeholder communication to justify technical decisions in business terms.

NOW WHAT: I will deepen my expertise in network security protocols and redundancy planning to design more resilient systems. I plan to pursue advanced certifications in network administration (CCNA) to strengthen my technical credentials. Additionally, I will develop better skills in presenting technical concepts to non-technical stakeholders, as infrastructure projects increasingly require business case justification and cost-benefit analysis.
